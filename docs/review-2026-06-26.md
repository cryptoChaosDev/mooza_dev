## 2. Пуш-уведомления — надёжность (DEV + PROD)

Жалоба: уведомления «то приходят, то нет», люди уходят. Диагностика показала: **отправка с сервера здорова** (ноль ошибок в логах, пуш-сервисы FCM/Apple/Mozilla достижимы 5/5 с РФ-хостов), значит дело ниже по течению. Главная находка — баг в маршрутизации чата.

| Коммит | Содержание |
|---|---|
| `4ec238c` | **Надёжная отправка**: `urgency: high` (будит спящий Android/Doze, приоритет у Apple) + `TTL` 3 дня (очередь для офлайн) + ретраи транзиентных сбоев. **Авто-переподписка при ротации** (`pushsubscriptionchange` в SW + новый no-auth `POST /api/push/resubscribe` по старому endpoint) — спасает редко заходящих, чьи подписки протухали. |
| `e862075` | Счётчик доставки `GET /api/push/stats` (под админом): sent/expired/failed + %доставки по сервисам. |
| `7e4e03a` | **Корневой баг чата**: `notifyUser` слал пуш **только если получатель оффлайн по сокету** — но PWA в фоне держит сокет живым → юзер «онлайн» → невидимый сокет-эмит и ноль пушей. Теперь пуш шлётся **всегда**, а SW гасит баннер только при активном (в фокусе) окне. |

Все три коммита **cherry-pick на `master` и выкачены на PROD** (`158162e → d29764d`), проверены смоуком. Честная оговорка: iOS Web Push в фоне Apple фундаментально троттлит — это лимит платформы; подстраховка — in-app уведомления по сокету. Через пару дней можно смотреть `/api/push/stats` на проде для реального % доставки.

## 4. Apple Music — автозаполнение и импорт релизов/клипов (DEV)

«Найти артиста» (Deezer + Apple Music) был только при создании. Расширили на редактирование и научились тянуть медиатеку.

| Коммит | Содержание |
|---|---|
| `1ae88f1` | Вынесен переиспользуемый компонент **`ArtistLookup`**; автозаполнение (название/тип/жанр/фото/ссылки) добавлено в **форму редактирования** артиста. |
| `4e4de70` | **Импорт релизов**: кандидат теперь несёт `itunesId`/`deezerId`; новый `GET /api/artist-lookup/releases?itunesId=` отдаёт альбомы Apple Music. В редактировании — список релизов с чекбоксами, «Импортировать выбранные» создаёт карточки (platform Apple Music), уже добавленные отфильтровываются. |
| `0c943a8` | **Импорт релизов сразу после создания** артиста (на экране успеха, где уже есть `id`) — без захода в «Редактировать». |
| `33ad2f6` | **Импорт клипов** Apple Music (entity=musicVideo). `ClipPlatform += APPLE_MUSIC` (миграция БД); клип открывается ссылкой «Открыть на Apple Music» (без встроенного плеера — выбор заказчика). Вынесен общий `MediaImportList` (один список для релизов и клипов в обоих флоу). |

Источник релизов/клипов — **Apple Music (iTunes API)**: из поддерживаемых платформ только она даёт прямые ссылки на альбом/видео. MusicBrainz по-прежнему недоступен из РФ (тип/Яндекс.Музыка — вручную).

## 5. Диагностика и обсуждения (без кода)

- **РФ-доступность DEV**: пользователь с конкретного IP (МегаФон-моб.) не открывал `dev.moooza.ru`.
