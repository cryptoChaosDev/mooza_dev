## 1. Фичи роста
1. **«Ищу музыканта»** (`/find`) — разбор фразы по справочникам (профессия/жанр/город/дата/бюджет/онлайн, морфология без LLM) → заказ с постом в Потоке → уведомление топ-10 исполнителям (`order_match`, ≤5/сутки на исполнителя, без повторов). Лимит 5 запросов в сутки на заказчика. *(api+web; `lib/requestParser.ts`, `lib/requestMatching.ts`, `lib/orderCreate.ts`, `routes/requests.ts`)*
2. **Визитка артиста** — блок «Слушать» (площадки по популярности в РФ), последний релиз, концерты из ЯМ, CTA «Пригласить на концерт» / «Подписаться» / «Поделиться» / QR (PNG), статистика просмотров и переходов для админов (`ArtistPageStat`, без ПДн, бот-фильтр, лимит 60/мин). *(api+web; новая зависимость `qrcode`)*
3. **Биржа лайнапов** (`/lineups`) — запросы организаторов, отклики от имени артиста, матчинг по городу/«готовы к гастролям»/жанру (≤20 артистов на запрос, ≤5/сутки артисту), SEO-снимок + `sitemap-lineups.xml`. *(api+web)*
4. **Подтверждённый опыт** — агрегат подтверждённых участий в релизах/клипах (`GET /users/:id/credits`), бейдж «N релизов» в каталоге. *(api+web)*
5. **Аудиодемо в каталоге** — ▶ 30 с на карточке (первое аудио портфолио, только `/uploads`). *(api+web)*
6. **⚡ «Отвечает быстро»** — медиана первых ответов в DM за 90 дней (≥5 диалогов), кэш в `User.responseBadge`, суточный пересчёт; гостю — только категория. *(api+web)*
7. **Telegram-канал @moooza_jobs** — автопостинг заказов/вакансий с хэштегами, закрытие поста при закрытии сущности (Prisma `$use`-хук, релей `TELEGRAM_API_BASE`). *(api)*
